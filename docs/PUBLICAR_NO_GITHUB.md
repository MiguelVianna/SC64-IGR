# Publicação no GitHub

Repositório público escolhido por Miguel: https://github.com/MiguelVianna/SC64-IGR

O conteúdo deste projeto foi separado do histórico privado de desenvolvimento.
A distribuição inclui apenas o menu autorizado, adaptação/fontes, licenças,
créditos, documentação e o formulário de incompatibilidade.

Para novas versões, revise os hashes e as notas, publique uma tag no formato
`v0.1.0-beta.1` e mantenha a indicação **pre-release**. O workflow incluído
confere os downloads e anexa o menu, HTML, fontes e checksums à release.

Se Actions estiver desabilitado ou falhar, use **Releases → Draft a new release**,
marque **pre-release**, copie as notas e anexe os quatro arquivos de downloads.
Os links do README continuam permitindo download direto pelo repositório.

Não publique ROMs comerciais, dumps, capturas privadas ou o histórico do RE264PTBR.

## Acesso da integração

Na primeira tentativa, o repositório estava público e vazio, mas o envio por
git e pela API retornou403. A API informou `Resource not accessible by integration`.
Inclua SC64-IGR nos repositórios autorizados da conexão GitHub deste chat e
avise para concluir a publicação. Isso não exige enviar senha ou token.
Alternativamente, envie os arquivos extraídos deste pacote pelo site do GitHub.
